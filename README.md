# Hoppibop Site

This repository hosts the public website for Hoppibop, including its privacy policy.

GitHub Pages deploys the site from the `main` branch at the repository root.

- Site: <https://hurstpreston-creator.github.io/hoppibop-site/>
- Privacy policy: <https://hurstpreston-creator.github.io/hoppibop-site/privacy.html>

A future `app-ads.txt` file should be added directly at the repository root so it is published at `/app-ads.txt`.

Before treating the privacy policy as final, replace the contact-email placeholder in `privacy.html` with a public support address.
